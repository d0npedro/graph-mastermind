# graph-explorer

Graph-Mastermind-Installation. Marker: `.graph-mastermind.json`.
Kein zweites `graph-explorer` in demselben Repo aufsetzen.

Referenz-SPA: Canvas 2D + d3-force, fünf Fallback-Datasets, kein Backend.

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

Die Runtime unter `src/graph/` ist zum Kopieren in ein Zielprojekt gedacht.
Datasets ersetzen, Canvas-Schicht nicht neu erfinden.

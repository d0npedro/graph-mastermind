# graph-explorer

Referenz-SPA für den Graph-Mastermind. Canvas 2D + d3-force,
fünf gebündelte Fallback-Datasets, kein Backend.

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

Die Runtime unter `src/graph/` ist zum Kopieren in ein Zielprojekt gedacht.
Datasets ersetzen, Canvas-Schicht nicht neu erfinden.
